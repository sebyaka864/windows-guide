# Practical optimization

Start with the changes that are easy to undo and make a visible difference. Measure how your PC feels before chasing benchmark scores.

## Trim startup apps

Open **Task Manager → Startup apps**. Disable launchers and helper apps you do not need immediately after sign-in. Leave security software, touchpad/audio controls, and anything you do not recognize enabled until you have researched it.

## Free up storage

Use **Settings → System → Storage → Temporary files** to review removable files. An SSD with comfortable free space tends to stay responsive; move large, unused files to external storage instead of relying on cleaner utilities.

## Pick an appropriate power mode

On a laptop, **Balanced** is usually the right default. Use a higher-performance mode only when plugged in and you need it. More aggressive power settings can increase heat, fan noise, and battery use.

## Keep security features on

Do not disable Microsoft Defender, the firewall, Windows Update, memory protections, or User Account Control just to claim a performance gain. The small potential benefit is rarely worth the loss of protection.
