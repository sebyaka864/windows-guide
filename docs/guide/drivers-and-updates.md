# drivers and updates

Windows Update should be your first stop after setup. It supplies security updates and many reliable drivers.

## recommended order

1. Run **Settings → Windows Update** until no important updates remain. Restart when asked.
2. Install your PC or motherboard maker's chipset, networking, and audio drivers if Windows has not already supplied a suitable version.
3. Install the graphics driver directly from [NVIDIA](https://www.nvidia.com/Download/index.aspx), [AMD](https://www.amd.com/en/support), or [Intel](https://www.intel.com/content/www/us/en/download-center/home.html) when applicable.
4. Restart, then confirm Device Manager has no unknown devices or warning icons.

:::caution avoid driver-updater utilities
Third-party driver scanners often bundle unwanted software or select incorrect drivers. Prefer Windows Update and the hardware manufacturer's support page.
:::

## firmware updates

BIOS/UEFI and SSD firmware updates can help in specific cases, but they carry more risk than ordinary drivers. Only apply them when the manufacturer documents a fix you need, and follow its instructions exactly.
