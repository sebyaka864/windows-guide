# Maintenance

A fast Windows install stays fast when you keep it simple.

## Monthly routine

- Install Windows and browser updates.
- Check that backups still complete and can be opened.
- Review startup apps after installing new software.
- Remove applications you no longer use through **Settings → Apps**.

## When troubleshooting

Change one thing at a time and record it. If a problem starts after a driver or app update, use the built-in rollback, repair, or uninstall option before trying broad “fix all” tools.

## When to reset or reinstall

Consider Windows recovery or a clean install when repeated problems remain after normal troubleshooting, malware is suspected, or you want to start over with a known-good software set. Back up first, every time.
